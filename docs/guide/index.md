# Guides

Step-by-step guides to build a package of Node-RED nodes. Each one has a goal, short code, and a result you can check
in Node-RED. Read them in order the first time, then come back to the one you need.

| | Guide | You will |
|---|---|---|
| 1 | [Your first node](./first-node) | scaffold a package, see your node in Node-RED, change its form and its runtime |
| 2 | [Build the form](./form-recipes) | show fields conditionally, add tabs, lists, code editors, typed inputs |
| 3 | [Write the runtime](./runtime) | read typed properties, set the status, send messages, run user scripts |
| 4 | [Config nodes and shared settings](./config-node) | share a server or an account between nodes, with "inherit from the client" |
| 5 | [Test and publish](./test-and-publish) | unit test a controller, check the editor, publish to npm |

::: tip Looking for a specific component or option?
Go to the [reference](/svelte/): [components](/svelte/components), [the node file](/svelte/node-file),
[CLI](/cli/build), [configuration](/config-file).
:::
